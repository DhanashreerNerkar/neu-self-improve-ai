Reinforcement Learning - University Projects
----------------------------------------------
1. Multi-GPU Distributed Infrastructure & Compute Optimization
Title: Multi-GPU Distributed Fine-Tuning & Compute Infrastructure
Description: Managed distributed fine-tuning workloads across multi-GPU NVIDIA A100 nodes, optimizing compute allocation, GPU memory utilization, and parallel execution pipelines for scalable AI systems research.

2. Reinforcement Learning Reasoning Pipeline
Title: RL-Driven Reasoning Pipeline (DeepSeek-R1 Distill on Modal A100)
Description: Engineered a custom PyTorch RL pipeline using DeepSeek-R1-Distill-Qwen-1.5B on Modal A100 clusters, boosting MATH benchmark accuracy from 12.5% to 30.6% via hybrid offline/online advantage optimization algorithms.

3. Self-Correcting LLM Framework
Title: Two-Stage LLM Self-Correction Framework (A*-PO + PAG)
Description: Developed a two-stage self-correction framework (A^*-PO + PAG) for Qwen2.5-1.5B in PyTorch, implementing verifier telemetry tracking and answer-change evaluation metrics to mitigate model collapse during iterative refinement.

4. LLM-MCTS Decision & Planning Agent
Title: LLM Monte Carlo Tree Search (MCTS) Planning Agent
Description: Built an interactive LLM-MCTS planning agent using Upper Confidence Trees (UCT), achieving a 52.5% boost in search efficiency and a 10x increase in reward return over random-walk baselines in WebShop environments.

5. Interactive Agent Evaluation Framework
Title: Cross-Environment Agent Evaluation Framework (WebShop & WebArena)
Description: Designed a unified evaluation benchmark bridging WebShop and WebArena, quantifying task-completion complexity through state transitions and retry metrics to reveal a $4.7x complexity gap between simulated and production environments.
